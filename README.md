# 💎 Finance Dashboard: Premium Liquid Glass UI

A **premium, full-featured Finance Dashboard** built on a state-of-the-art **React 19** and **Vite 7** technical stack with a stunning **"Liquid Glass"** aesthetic. Features intuitive **tabbed navigation**, rich **Recharts** visualizations, and privacy-first **local storage** persistence—delivering a professional-grade experience for modern developers and users.

---

## 🎨 Design Philosophy
This project is defined by its signature **Liquid Glass** UI—a modern glassmorphism design featuring high-blur backdrops, vibrant gradients, and elegant micro-animations powered by **Framer Motion**. This minimalist yet rich interface is built with **TypeScript** and **Tailwind CSS**, ensuring a scalable, type-safe architecture that feels alive and responsive across all devices.

## 🚀 Core Features

### 📊 Dashboard & Analytics
- **Instant Financial Summaries**: Real-time balance, income, and expense tracking.
- **Interactive Trends**: High-performance visualizations for balance growth and spending breakdowns powered by **Recharts**.
- **Intuitive Navigation**: Seamless transitions between **Dashboard**, **Transactions**, and **Insights**.

### 🔒 Privacy & Security
- **Local-Only Data**: All financial information is stored securely in the user's browser, providing 100% privacy and private-by-default security with **zero external database dependencies**.

## 🛠 Technical Stack
- **Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with a custom Liquid Glass theme.
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Charts**: [Recharts](https://recharts.org/)
- **Build Tool**: [Vite 7](https://vite.dev/)

## 🏗 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sandeep-svg-45/finance-dashboard.git
   ```

2. **Navigate to the app folder**:
   ```bash
   cd app
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Run development server**:
   ```bash
   npm run dev
   ```

---

## 🌐 Deployment
This project is optimized for high-performance static hosting. To deploy:

1. **Build the production bundle**:
   ```bash
   npm run build
   ```

2. **Host on your platform of choice**:
   - **Netlify**: Drag-and-drop the `app/dist` folder.
   - **Vercel**: Run `npx vercel` in the `app` folder.
